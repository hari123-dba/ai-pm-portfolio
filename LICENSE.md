# Licensing

**Pick before you push** (then delete this note):

- **Code** (scripts, prototypes): MIT is the simplest permissive default. Add a `LICENSE`
  file from GitHubs "Add license" picker when you create the repo.
- **Written work** (teardowns, case studies, notes): consider
  **CC BY-NC 4.0** so others can share with attribution but not resell your writing,
  or simply "© [year] Hari Hara Kumar — all rights reserved" for the prose.

GitHub can add a standard LICENSE file for you during repo creation — easiest path.
